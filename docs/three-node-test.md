# 三节点测试（vboxdeb001/002/003）

日期：2026-10-02　后端：内核 UDP（`make SX_NO_XDP=1 group-tools tests-throughput`）

## 环境

| 节点 | 管理网（SSH） | 测试网卡 enp0s9 |
| --- | --- | --- |
| vboxdeb001 | 172.22.133.251 | 192.168.77.101 |
| vboxdeb002 | 172.22.133.252 | 192.168.77.102 |
| vboxdeb003（新增） | 172.22.133.253 | 192.168.77.103 |

VirtualBox internal 网络二层；三节点均已部署并编译。

## 1. 组播（101 发；102/103 各 2 收）

组 `239.3.3.3:48200`，`multicast_if` 分别设为各节点测试网地址；1000 条。

```
102: m2_1 got=1000  m2_2 got=1033
103: m3_1 got=1074  m3_2 got=1003
```

全部收到约 1000（ooo≈7~8），存在少量重复投递（got>expect）。

## 2. 广播（101 发；102/103 各 2 收）

`192.168.77.255:48201`，1000 条。

```
102: b2_1 got=1004  b2_2 got=1003
103: b3_1 got=958   b3_2 got=1005
```

广播本次可用（103 有约 4% 尽力可靠丢失）。注意：VBox internal 网络广播不稳定，
此前两节点测试曾出现全 0；物理机（10.45/10.46）验证稳定。

## 3. 单播全互联（p2p mesh）

每对 100,000 条 × 1400B：

| 方向 | 吞吐 | msg/s | 客户端重传 | 服务端收到 |
| --- | --- | --- | --- | --- |
| 101 -> 102 | 63.75 MB/s | 45,535 | 40,590 | 100,000 |
| 101 -> 103 | 93.38 MB/s | 66,703 | 13,076 | 100,000 |
| 102 -> 103 | 112.24 MB/s | 80,173 | 36,577 | 200,000（含 101->103） |

全部零丢失（outstanding=0，服务端计数精确），体现单播严格可靠有序。

## 4. 结论

- 三节点下**组播/广播可用**（组播较稳；广播受 VBox 环境波动），存在组播/广播的少量重复投递与乱序。
- 三节点**单播全互联**可靠有序，零丢失。
- 需要严格可靠的点对多，仍建议单播扇出。
